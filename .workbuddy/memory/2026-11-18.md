## lib 作为 JitPack 库发布（maven-publish）
- JitPack 报错 `Too many characters in a character literal`（lib/build.gradle.kts:5）根因：
  在 `.kts` 里用了 Groovy 的单引号 `singleVariant('release')`，Kotlin 只允许 `"release"`。
- 已在 `lib/build.gradle.kts` 补全发布配置：`plugins { `maven-publish` }` +
  `android { publishing { singleVariant("release") { withSourcesJar() } } }` +
  `afterEvaluate { publishing { publications { create<MavenPublication>("release") { from(components["release"]) } } } }`。
  注意需要 `import org.gradle.api.publish.maven.MavenPublication`。
- 验证：`./gradlew :lib:publishToMavenLocal --offline` BUILD SUCCESSFUL，
  产出 `~/.m2/repository/com/github/jeraypop/lib/1.0.0/` 下 aar + sources.jar + pom + module。
- 关键事实：本地与远端 HEAD 都是 99e63b4，而该提交里**没有** publishing 块 ——
  JitPack 编译的是已不在 master 上的提交，改完必须重新提交并触发新构建。
- 仓库目前无任何 tag，JitPack 只能用 `master-SNAPSHOT`，正式坐标建议打 tag 后用
  `com.github.jeraypop.WXAPK:lib:<tag>`。
- 附带好处：`gradle/gradle-daemon-jvm.properties`（toolchainVersion=25）已 gitignore，
  JitPack 不会被迫去下载 JDK 25。
